This project uses Terraform to provision a complete AWS infrastructure and deploy a Flask web application in a single `terraform apply` command — Terraform first creates a VPC with one public subnet, an Internet Gateway, a route table pointing all traffic to the IGW, and a security group opening ports 22 (SSH), 80 (HTTP), and 5000 (Flask) — then launches a t2.micro EC2 instance in that public subnet with `associate_public_ip_address = true` so it gets a reachable public IP — and then without any manual intervention, the `connection` block establishes an SSH tunnel to the EC2 using the private key file from your laptop, the `file` provisioner copies `app.py` from your local machine to `/home/ubuntu/app.py` on the EC2 over that SSH connection, and the `remote-exec` provisioner runs a sequence of shell commands over the same SSH connection — `apt-get update`, installing `python3-venv`, creating a virtual environment at `/home/ubuntu/flask-env`, installing Flask inside it, and starting the app with `nohup /home/ubuntu/flask-env/bin/python app.py > flask.log 2>&1 &` where `nohup` keeps Flask alive after SSH disconnects and `&` runs it in the background so Terraform does not wait forever — after which `terraform apply` completes and prints the public IP and full Flask URL in the outputs, making the app immediately accessible in a browser at `http://<public_ip>:5000` with three endpoints: `/` for the home page, `/health` for a JSON health check, and `/info` for server details.
